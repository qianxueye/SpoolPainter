# Kozen POS 使用与验证

安装后在连接设置填入你的 Spoolman HTTP/HTTPS 地址。库存首页的刷新只读取服务器；不会自动创建厂商、耗材、线卷或自定义字段。库存读取遇到连接中断时会自动重试一次；新增、修改、消耗等写入请求不会自动重试，结果未知时仍需先刷新核对。POS 终端需授予厂家打印机和非接触读卡权限，局域网访问可选择仅 WLAN。

库存、耗材和厂商页提供原生新增、详情、编辑和删除。归档不会删除线卷。毛重称量使用克，先明确设置该卷空盘重量；记录消耗提交的是增量，保存结果不明时需要先刷新核对，不能直接重试。编辑元数据不会把缓存中的剩余重量一起覆盖。

扫描标签后可按 UID 查找、绑定或解绑。重复 UID 会阻止自动选卷和改绑，包括已归档的线卷。标签读写页沿用上游 OpenSpool 工作流；POS 适配的写入范围只覆盖已验证的 NTAG216 用户区，并检查身份、锁定、密码保护、镜像和页地址。拓竹标签在 POS 路径中仅按 UID 识别，不写入其加密材料区。任何写卡均需操作员明确触发。

库存首页右上角的二维码按钮可打开相机扫描。首次使用需允许相机权限；默认使用后置相机，并在后置相机有闪光灯时自动开启补光。画面右下角的圆形手电筒图标可随时开关补光，亮起时使用主题金色；没有闪光灯的相机显示禁用图标。设备同时提供前后相机时，旁边的相机图标可切换镜头。切换或退出时会关闭原相机补光，切回后置相机时重新自动开启。页面同时显示当前前／后置相机及实际补光状态。预览就绪后自动进行中心对焦和测光，也可轻点画面中的纸质二维码重新对焦；若仍模糊，请适当拉远或靠近，并避开纸面反光。补光、对焦或相机错误会显示在扫描页。支持 `WEB+SPOOLMAN:S-<id>`、当前服务器的 `/spool/show/<id>` 地址，以及该页面跳转后的 `/?sel=spool:<id>` 链接。识别后会重新读取对应线卷并打开详情，也支持已归档线卷。其他服务器、耗材类型二维码和无效编号会显示错误，不会改动库存。识别由本机 CameraX 与 ZXing 完成，不需要 GMS，也不会上传相机画面。取消或离开扫描页会释放相机。

选择线卷后打开打印预览。实际打印前重新读取当前服务器中的记录，避免打印旧重量或同编号的另一台服务器记录。二维码使用 `/spool/show/<id>` 网页地址或 `WEB+SPOOLMAN:S-<id>` 标准识别码。纸尾默认 1.5 厘米，可在打印页保存其他长度。

连续小票顶部显示并打印 INSLOGIC、Polymaker、Snapmaker、Bambu Lab 或 Kexcelled 的品牌标志，按厂商名称精确匹配，忽略大小写和首尾空白；BambuLab 和“拓竹”是 Bambu Lab 的明确别名。Generic 及其他厂商保留品牌文字，不猜测标志。标志使用随应用附带的厂家素材，按比例居中转为白底黑色，预览与两种小票打印路径使用相同渲染方式。实际提交按最新读取的厂商名称选择标志；已知品牌素材准备失败会显示错误，不会回抽或开始打印。定长标签的字段和布局不变。

小票纸模式另有“打印前回抽 1 cm”实验开关，默认关闭，开关选择仅保存在本机。定长标签模板不显示也不使用此选项，模板中不保存回抽设置。启用后，正常点击打印即先回抽再输出小票；请确保使用连续小票纸，纸路无阻挡、纸张能自由移动。回抽选项在提交时随任务固定，读取最新线卷期间或队列等待期间更改开关，不会改变已经提交的任务。

应用只在明确点击打印后、最新记录读取和打印准备成功后执行回抽，再开始原有小票输出。应用只调用一次原始回抽指令，量值为 -80，不会拆成多个较小段，也不改变独立 Demo。厂商底层在 ACK 超时或 NAK 分支可能将整帧原生重发最多 9 次；没有证据证明设备按重复序号去重，因此一次应用调用不能保证只发生一次物理运动。极端情况下可能累计执行 720 个原始单位；按每毫米 8 个单位的假设约为 90 mm，另可能有对齐运动，实际距离和速度不保证。执行判定要求回抽窗口内恰好一个发送、一个 ACK 和一个完整关联响应；检测到重发或故障会隔离后续打印，但不能撤销已发生的运动。应用本身不自动重试回抽。厂商共享库及必要权限不可用时会显示原因，包括开发用途的 READ_LOGS 权限；应用不会自动授予权限或启用开关。关闭回抽可按原方式提交小票打印。若回抽是否执行无法确认，页面会显示实际原因并暂停打印，不提供直接重试；未发送的准备失败则允许操作员修正后明确重试。进入打印页仍会解除 NFC 扫描，打印页退出时保留原有打印资源生命周期管理。回调超时也会隔离队列，需先查看纸张确认结果，避免重复输出。

POS 读卡顺序为 PICC 打开、MIFARE 打开和操作、MIFARE 关闭、PICC 关闭。这样由厂家服务处理设备启用的触摸屏/NFC 共存模式。读取 NTAG216 时按 NDEF 长度获取所需页面；空标签立即返回，不为读取标签而扫描整片未使用内存。应用不直接写 sysfs，也不在后台持续扫描，不改永久射频参数。初始化或清理无法确认时会停止后续读卡，而非不断重试。

主题沿用上游金色 Material 主题；库存首页、标签页、打印页和中文文案是本 fork 的适配。厂商 SystemUI 的交易风险水印与应用页面无关。静态逆向发现其条件涉及厂商测试机标志、ADB 开关和启动状态；是否关闭调试后立即隐藏需要系统刷新，不能以应用改色冒充水印已删除。

本地构建需 JDK 21、Android SDK 36、Build Tools 35 和项目固定的 Gradle 8.14.3：

```sh
./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

厂家 `com.pos.sdk` 使用设备已有的可选共享库，源码通过反射调用其公开接口，不需要下载或提交厂家 JAR。没有该共享库的普通 Android 设备保留标准 NFC 路径，内置 Kozen 打印不可用。应用包名与上游分开，调试包为 `cc.apture.spoolpainter.pos.debug`。升级须保留相同签名密钥；CI 构建用于验证，不应直接覆盖另一签名安装的本地版本。
